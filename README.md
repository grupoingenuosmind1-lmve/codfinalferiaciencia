# Módulo Complementario de Odometría y Control Giroscópico: Proyecto de Navegación

>## El código en MakeCode publicado: https://makecode.microbit.org/S29383-24298-60091-27753


## Descripción del Complemento
Este módulo corresponde a una extensión técnica desarrollada como paso previo a la Feria de Ciencia y Tecnología, concebida para fortalecer y robustecer la base algorítmica previa del prototipo. La propuesta integra una capa adicional de interacción y seguridad mediante un control giroscópico y manual gestionado por la tarjeta Micro:bit, junto con un sistema de validación posicional basado en odometría. Esta arquitectura actúa como un amplificador del pensamiento computacional, convirtiendo la lógica de los estudiantes en el núcleo del sistema sobre una infraestructura modular y escalable.

---

## Descripción de la Extensión Técnica
El complemento consiste en un sistema de adaptación dinámica en tiempo real que optimiza el comportamiento del robot en el entorno de pruebas, previniendo colisiones ante nuevos retos y permitiendo que la misma estructura lógica responda a diversas configuraciones del laberinto.

La arquitectura técnica integrada se compone de:
- Un módulo de validación posicional por odometría para el seguimiento y ajuste de las trayectorias del robot.
- Un sistema de control giroscópico y manual guiado por la tarjeta BBC micro:bit para la supervisión y prevención de colisiones en tiempo real.
- Un núcleo algorítmico desarrollado en Python que procesa la lógica de navegación y otorga versatilidad al prototipo ante múltiples entornos.
